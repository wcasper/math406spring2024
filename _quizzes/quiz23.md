**Question 1:**  True or false.

If $$\widetilde u(x,y,z,t)$$ is a solution of the wave equation in three dimensions

$$\widetilde u_{tt} = c^2(\widetilde u_{xx} + \widetilde u_{yy} + \widetilde u_{zz})$$

with the initial condition

$$\widetilde u(x,y,z,0) = f(x,y),\ \ \widetilde u_t(x,y,z,0) = g(x,y)$$

then $$u(x,y,t) = u(x,y,0,t)$$ is a solution of the wave equation in two dimensions

$$u_{tt} = c^2(u_{xx} + u_{yy})$$

with the initial conditions

$$u(x,y,0) = f(x,y),\ \ u_t(x,y,0) = g(x,y).$$


**Question 2:**  True or false.

If $$\widetilde u(x,y,z,t)$$ is a solution of the wave equation in three dimensions

$$\widetilde u_{tt} = c^2(\widetilde u_{xx} + \widetilde u_{yy} + \widetilde u_{zz})$$

with the initial condition

$$\widetilde u(x,y,z,0) = f(x),\ \ \widetilde u_t(x,y,z,0) = g(x)$$

then $$u(x,t) = u(x,0,0,t)$$ is a solution of the wave equation in one dimension

$$u_{tt} = c^2u_{xx}$$

with the initial conditions

$$u(x,0) = f(x),\ \ u_t(x,0) = g(x).$$


**Question 3:**  True or false.

$$u(x,y,t) = x^3 + x^2y + (3x + y)c^2t^2$$

is a solution of the wave equation

$$u_{tt} = c^2(u_{xx}+u_{yy})$$

with the initial condition

$$u(x,y,0) = x^3 + x^2y,\ \ u_t(x,y;0) = 0.$$
