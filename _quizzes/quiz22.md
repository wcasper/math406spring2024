**Question 1:**  True or false.

If $$u(\rho,\theta,\phi,t)$$ is a spherically symmetric solution of the wave equation 

$$u_{tt} = c^2 \Delta u,$$

then

$$u_{tt} = c^2\left(u_{\rho\rho} + \frac{2}{\rho}u_\rho\right).$$

**Question 2:**  True or false.

If $$u(x,y,z,t)$$ is a solution to the wave equation in three dimensions

$$u_{tt} = c^2 \Delta u,$$

then the spherical mean $$\overline u(x,y,z,t;r)$$ satisfies

$$u_{tt} = c^2\left(u_{rr} + \frac{2}{r}u_r\right).$$

**Question 3:**  Numerical.

Determine the spherical mean $$\overline f(x,y,z; r)$$ of $$f(x,y,z) = x$$ for $$r=5$$ and $$(x,y,z) =(1,2,3)$$.

**Question 4:**  True or false.

A solution of the initial value problem 

$$u_{tt} = c^2 \Delta u,$$

with the initial condition

$$u(x,y,z,0) = f(x,y,z),\ \ u_t(x,y,z,0) = g(x,y,z)$$ is given by

$$u(x,y,z,t) = \overline f(x,y,z; ct) + ct\overline f_r(x,y,z; ct) + t\overline g(x,y,z; ct).$$
